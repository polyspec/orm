# orm — Rust client

Two crates in one workspace, plus the test binaries:

| crate | what |
|---|---|
| `orm` (`clients/rust/orm`) | the executor: wasm compiler boundary (wasmtime), plan cache keyed by IR shape, sqlx runner, codecs, `orm.toml` loader, error codes |
| `gen` (`clients/rust/gen`) | generated by `ormgen gen --schema schema/schema.json --lang rust --out clients/rust/gen`; one module per entity, `gen::SCHEMA_HASH`, `gen::init` |
| `orm-tests` (`clients/rust/tests`) | `integration`, `conformance`, `client_bench`, `demo` (`examples/thin-slice/rust/main.rs`) |

Both library crates are `MIT OR Apache-2.0`, version 0.0.1.

## Startup

```rust
let db = orm::Db::from_config("/srv/app/orm.toml").await?;   // [db], [engine], [secrets], [debug]
gen::init(db.engine.clone())?;                                // schema_hash boot check, once
let row = gen::Battle::new().one_by_seq(&db, 42).await?;
```

`orm.toml` is described in `docs/config.md`. The Rust client reads:

- `schema` — the manifest the engine loads; `gen::init` compares its `schema_hash` with
  `gen::SCHEMA_HASH` exactly once and fails with `SCHEMA_HASH_MISMATCH` (no watching, no reload).
- `[db].dsn` — a sqlx URL (`mysql://root@localhost/orm_bench?socket=/tmp/mysql.sock`); `user`/`password`
  apply only when the URL carries no user, a different user in both is `CONFIG`; `pool` is the pool size.
- `[secrets].aes` or `aes_env` (one of them; required when the schema has `aes` columns).
- `[engine].wasm`, `[engine].cache_dir` — see below.
- `[debug].on_query = true` — logs every statement to stderr.

Every path must be absolute, exist and not be a symlink (`std::fs::symlink_metadata` on the path
itself); anything else is a `CONFIG` error at startup. Nothing is discovered.

Without a config file, `Db::connect(opts, pool, engine, Config { aes_key, on_query })` takes the
pieces directly (what the test binaries do).

## The wasm engine

The engine is `bin/ormengine.wasm` (`GOOS=wasip1 GOARCH=wasm go build -buildmode=c-shared -o
bin/ormengine.wasm ./engine/wasm`). The client loads it **at runtime** from the declared path
`[engine].wasm` (`Db::from_config`) or from bytes you pass to `Engine::new` (`EngineConfig { wasm,
schema_json, cache_dir }`). `cache_dir` is where wasmtime may keep its compiled-module cache;
declare it (absolute, existing, not a symlink) or leave it unset for no cache.

Embedding at build time is an option, not something the crate does for you: declare the path in an
environment variable at build time and include it from your application —

```rust
// build with ORM_WASM=/abs/path/to/ormengine.wasm (an absolute path to a real file, never a symlink)
static WASM: &[u8] = include_bytes!(env!("ORM_WASM"));
let engine = orm::Engine::new(orm::engine::EngineConfig { wasm: WASM, schema_json: &schema, cache_dir: None })?;
```

`include_bytes!` resolves the path at compile time, so the binary carries the engine and
`[engine].wasm` is not needed; the schema is still read from `schema` at startup for the hash check.

## Errors

`orm::codes` is generated from `docs/errors.yaml` (`ormgen errors --lang rust --out
clients/rust/orm/src/codes.rs`). Engine codes pass through as `Error::Engine { code, msg }`; the
executor raises `Error::Config` (`CONFIG`) and `Error::OptimisticLock`; driver errors stay
`Error::Sqlx` except MySQL 1213 / SQLSTATE 40001 → `DEADLOCK` and 1062 / SQLSTATE 23000 →
`DUPLICATE_KEY`, which become `Error::Engine` with the driver's message. `Db::transaction`
re-runs the closure on `DEADLOCK` (up to 3 attempts).

## The statement hook

`Config.on_query: Option<OnQuery>` with `OnQuery = Box<dyn Fn(&str, &[Param], Duration, u64,
Option<&Error>)>`: `(sql, binds, duration, plan_id, err)` per statement. Secret binds (the AES
key) are passed as `Param::Str("$SECRET")`. `plan_id` is the plan-cache key — FNV-1a 64 of the IR
shape bytes — render it as `{plan_id:016x}` to group log lines by statement shape. `sql(&db)`
returns the same `plan_id` without executing.

## Build and test

```sh
export PATH="$HOME/.cargo/bin:$PATH"
cd clients/rust && cargo build --release && cargo test --release -p orm
./target/release/integration ../../bin/ormengine.wasm ../../schema/schema.json
./target/release/conformance ../../bin/ormengine.wasm ../../schema/schema.json
./target/release/demo        ../../bin/ormengine.wasm ../../schema/schema.json
```

The binaries connect to `root@/tmp/mysql.sock`, database `orm_bench`, unless `ORM_MYSQL_URL_RUST`
is set (a sqlx URL; CI sets `mysql://root@127.0.0.1:3306/orm_bench`).

# S6 언어 레인 — PostgreSQL과 SQLite

Engine은 `engine.New(m, "postgres" | "sqlite")`를 사용한다. 방언 차이는 docs/dialects.md에 기록한다. Plan 구조는 같고 executor 차이만 아래 항목에 기록한다.

## 1. 결과물 (언어별)
| 항목 | 내용 |
|---|---|
| database별 driver | Go: `pgx` stdlib와 `modernc.org/sqlite`; Rust: sqlx `postgres`, `sqlite`; PHP: `pdo_pgsql`, `pdo_sqlite`. `orm.toml [db].driver = "mysql" | "postgres" | "sqlite"`가 선택하며 engine 방언과 같아야 한다. |
| `$n` 재번호 | PostgreSQL에서 parent slot을 N개 placeholder로 확장할 때 뒤의 모든 `$k`를 다시 번호화한다. slot 순서와 pow2 padding 규칙을 유지한다. |
| host codec | `aes`: 12바이트 nonce와 version key를 사용하는 인증된 AES-256-GCM v2, `hex`: 대문자, `ip`: SQLite에서 packed bytes와 read 시 text를 사용한다. 고정 AES vector는 `tests/codec/aes-vectors.json`이다. |
| type mapping | PG boolean, datetime(6), decimal, JSONB, `RETURNING`을 각 client 타입으로 변환한다. |
| bench DDL | `ormgen ddl --dialect`가 생성한 `bench/sql/battle.pg.sql`과 `bench/sql/battle.sqlite.sql`을 저장한다. |
| 적합성 | 세 database의 44 vector 결과가 같아야 한다. statement는 방언별로 다를 수 있다. |

## 2. 규칙
docs/lanes/s3.md §4 규칙을 적용한다. PostgreSQL은 `deploy/docker-compose.yml`을 사용하고 SQLite는 scratch directory의 file을 사용한다.

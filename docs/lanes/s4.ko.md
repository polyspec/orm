# S4 언어 레인 — 집계, having, raw root, 이름 있는 predicate

Engine 규칙은 IR kind `count_distinct`, `min`, `max`, root `having: Group`, group count, `kind: raw`, entity별 `predicates`를 사용한다. 자세한 내용은 docs/protocol.md의 집계 확장과 docs/dsl.md에 기록한다.

## 1. 추가 API
| token | 내용 |
|---|---|
| `countDistinct<Col>(db)`, `min<Col>(db)`, `max<Col>(db)` | 허용된 column에 typed 결과를 반환한다. `countDistinct`는 int를 반환한다. |
| `getCount()`, `getsCount()` | 일반 count 또는 group 수와 group row를 반환한다. |
| `having(fn)` | query에서만 사용하며 같은 Where builder로 having group을 작성한다. |
| `raw(sql, binds)`, `rawAll(db)` | root raw statement를 저장하고 column 이름을 key로 하는 ordered map 목록을 반환한다. |
| `<name>(args…)` | manifest predicate별 method를 query와 Where에 생성하고 expr fragment와 인자를 사용한다. |

## 2. 적합성 vector
1. `agg_min_max`는 min, max, count distinct 결과를 비교한다.
2. `group_count_having`은 group과 having 결과를 비교한다.
3. `predicate_named`는 이름 있는 predicate 결과를 비교한다.
4. `raw_root`는 raw query의 ordered map 결과를 비교한다.

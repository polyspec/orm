## 공통 완료 조건

S7 항목은 구현·테스트·문서·정적 게시를 모두 완료해야 닫는다. Go·PHP·Rust·TypeScript에서 같은 논리 구조를 사용할 수 없는 기능은 구현하지 않는다.

FrankenPHP in-process 실행은 PHP 런타임 전용 최적화이며 공통 API와 자료 구조가 없으므로 S7에서 제외한다.

## T7.3 마이그레이션 명령

```sh
go run ./cmd/ormgen diff \
  --from old-schema.json \
  --to schema/schema.json \
  --dialect mysql \
  --out migration.sql
```

이 명령은 파괴 옵션 없이 `ADD COLUMN`과 신규 테이블 SQL을 생성한다. 테이블 삭제, 컬럼 삭제, 컬럼 정의 변경이 있으면 실패한다. 파괴 SQL을 검토한 경우에만 `--allow-destructive`를 추가한다.

## T7.7 precompile 명령

```sh
go run ./cmd/ormgen precompile \
  --schema schema/schema.json \
  --dialect mysql \
  --in request.json \
  --out plan.json
```

출력에는 `version`, `schema_hash`, `dialect`, `request_sha256`, `plan`이 포함된다. 클라이언트는 plan을 로드하기 전에 `schema_hash`를 비교한다.

컴파일러 wire 정의는 `proto/orm/compiler/v1/compiler.proto`다. `npm run proto:check`는 RPC 이름과 typed message 선언을 검사한다. 언어별 생성 binding, Connect 서버 처리, 언어 간 벡터 실행은 T7.1 잔여 작업이다.

## T7.4 scope 지시문

```text
%% scope battle service_seq
```

지시문은 존재하는 NULL 불가 정수·문자열·enum 컬럼을 요구한다. 생성 클라이언트는 `scope(value)`를 제공하고 equality predicate로 인코딩한다. 현재 benchmark 스키마에는 `battle.service_seq`를 적용했다. T7.4를 완료하려면 테넌트 분리 테스트가 필요하다.

AES 컬럼은 NULL 불가 정수 `aes_key_version` 컬럼을 요구한다. `npm run schema:check`는 생성 manifest를 검사하고 schema builder도 `schema.json` 기록 전에 같은 규칙을 적용한다. Go는 버전별 키 목록과 한 행의 모든 AES 컬럼을 재암호화하는 함수를 제공한다. 모든 AES 컬럼 처리가 성공하기 전에는 입력 행을 변경하지 않는다. 호출자는 반환된 AES 컬럼과 버전을 하나의 트랜잭션으로 저장해야 한다. 데이터베이스 행 순회, 상태 조회, PHP·Rust·TypeScript API는 T7.13 잔여 작업이다.

```go
keyring, err := orm.NewAESKeyring(map[int32]string{1: oldKey, 2: newKey}, 2)
rotated, err := orm.RotateAESRow(row, "aes_key_version", columns, 2, keyring)
```

## T7.8 TypeScript 구조 검사

TypeScript 어댑터는 `clients/typescript/src/index.ts`에 공통 request, query, where, row, compiler, executor 타입을 정의한다. 생성 진입점은 `battle`, `user`, `service`, `service_module`, `service_member`를 포함하며 선언되지 않은 엔티티에서 `scope()`를 호출하면 오류를 반환한다. `npm run typescript:check`는 TypeScript 컴파일러를 실행하고 `node tests/typescript/check.mjs`는 선언과 메서드 순서를 검사한다. TypeScript 실행기가 공통 벡터를 통과할 때까지 S7 항목은 미완료로 유지한다.

# 문서 및 변경 규칙

영어 Markdown 파일을 정본으로 사용한다. 한국어 번역은 같은 경로에 `.md` 앞에 `.ko`를 추가한다.

예시는 다음과 같다.

- `docs/usage.md` 및 `docs/usage.ko.md`
- `docs/examples/complex-query.md` 및 `docs/examples/complex-query.ko.md`

다음 규칙은 저장소 검사기가 강제한다.

1. 모든 영어 Markdown 페이지에는 한국어 번역이 하나 있어야 한다.
2. 번역의 제목, 코드 블록, 표, 링크, 항목 ID는 영어 문서과 일치해야 한다.
3. 매뉴얼은 주체와 대상을 명시한 직접적인 문장을 사용한다.
4. 매뉴얼은 비격식 종결, 비유, 의인화, 모호한 지시를 사용하지 않는다.
5. 새 코멘트와 커밋 메시지에는 대화 기록과 불필요한 출처 표기를 넣지 않는다.
6. 새 커밋 메시지는 `type: 간결한 영어 설명` 형식을 사용한다.
7. 체크리스트 항목은 구현, 테스트, 문서, 정적 배포가 모두 통과한 뒤에만 완료로 표시한다.

기계 판정 규칙은 `contracts/rules.json`에 저장한다.

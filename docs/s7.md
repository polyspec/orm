## Common completion rule

An S7 item is complete only when implementation, tests, documentation, and static publication are complete. A feature that cannot use the same logical structure in Go, PHP, Rust, and TypeScript remains unimplemented.

FrankenPHP in-process execution is excluded from S7 because it is a PHP runtime-specific optimization and has no common API or data structure.

## T7.3 migration command

```sh
go run ./cmd/ormgen diff \
  --from old-schema.json \
  --to schema/schema.json \
  --dialect mysql \
  --out migration.sql
```

The command emits `ADD COLUMN` and new table statements without the destructive option. It fails when the change removes a table or column or changes a column definition. Add `--allow-destructive` only when the migration review includes the destructive SQL.

## T7.7 precompile command

```sh
go run ./cmd/ormgen precompile \
  --schema schema/schema.json \
  --dialect mysql \
  --in request.json \
  --out plan.json
```

The output contains `version`, `schema_hash`, `dialect`, `request_sha256`, and `plan`. A client must compare `schema_hash` before loading the plan.

## T7.4 scope directive

```text
%% scope battle service_seq
```

The directive requires an existing non-null integer, string, or enum column. Generated clients expose `scope(value)` and encode it as an equality predicate. The current benchmark schema uses `battle.service_seq`; tenant isolation tests and the TypeScript generated entity set are still required before closing T7.4.

AES columns require a non-null integer `aes_key_version` column. `npm run schema:check` verifies the generated manifest, and the schema builder applies the same rule before writing `schema.json`. Go now provides a versioned key list and an all-column row rotation helper. The helper leaves the input row unchanged until every AES column succeeds; database callers must persist the returned AES columns and version in one transaction. Database row iteration, status reporting, and equivalent PHP, Rust, and TypeScript APIs remain open T7.13 work.

## T7.8 TypeScript structure check

The initial TypeScript adapter defines the common request, query, where, row, compiler, and executor types in `clients/typescript/src/index.ts`. `npm run typescript:check` runs the TypeScript compiler, and `node tests/typescript/check.mjs` checks declarations and method order. The S7 item remains incomplete until the generator emits the same API for every entity and the TypeScript runner passes the common vectors.

The compiler wire definition is `proto/orm/compiler/v1/compiler.proto`. `npm run proto:check` verifies the RPC name and typed message declarations. Generated language bindings, Connect server handling, and cross-language vector execution remain open T7.1 work.

# Security policy

## Reporting

Report a suspected security issue privately to the repository owner before opening a public issue. Include the affected version, database driver, client language, reproduction steps, and impact. Do not include live credentials or production data.

## Supported version

The development version is `0.0.1`. Security fixes are evaluated against the current source tree.

## Scope

Reports may cover SQL generation, parameter binding, compiler transport validation, encryption and key rotation, migration execution, and generated client code. A database driver or dependency vulnerability should also include the affected dependency version.

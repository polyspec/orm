# Thin-slice demo

The same statement in three files; the same JSON on stdout.

```
go run ./examples/thin-slice/go schema/schema.json
php examples/thin-slice/php/main.php /abs/schema/schema.json
(cd clients/rust && cargo build --release -p orm-tests) && clients/rust/target/release/demo
```

Each prints one timing line on stderr: p50 of the generated client against the
plan's SQL run again through the native driver (`database/sql` / PDO / sqlx) in the
same process — the client's fixed per-statement cost on a 3-row query.

The programs read the seeded MySQL bench database. Every program takes the DSN from `ORM_BENCH_MYSQL_DSN`; the default is `mysql://root@localhost/orm_bench?socket=/tmp/mysql.sock`. The Go and PHP programs take the schema path as their argument; the Rust models are generated by `orm-build` when the binary is built.

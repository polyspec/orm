# Thin-slice demo

The same statement in five files; the same JSON on stdout.

```
go run ./examples/thin-slice/go
php examples/thin-slice/php/main.php
(cd packages/rust && cargo build -p polyspec-orm-tests) && packages/rust/target/debug/demo
node examples/thin-slice/ts/main.mts
packages/python/.venv/bin/python packages/python/examples/thin_slice/main.py
```

Each prints one timing line on stderr: p50 of the generated client against the
plan's SQL run again through the native driver (`database/sql` / PDO / sqlx / mysql2 / PyMySQL) in the
same process — the client's fixed per-statement cost on a 3-row query.

The programs read the seeded MySQL bench database. Every program takes the DSN from `ORM_BENCH_MYSQL_DSN` and exits with status 1 without connecting when it is unset or empty. The Go and PHP models carry their manifest, and the Rust models are generated by `polyspec-orm-build` when the binary is built. The TypeScript and Python models are generated from the bench set with this program in their scan lists (`packages/ts/package.json` `models`, `Makefile` `python-model-check`).

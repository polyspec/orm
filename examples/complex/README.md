# Complex statement demo

One statement with the main parts of the grammar, in three languages, printing the **same compact JSON bytes**:

- a join child with its own `on()` conditions whose `where` conditions are placed in a group with `or(model)`,
- two levels of relations with options (`groupLimit`, `alias<Name>`, `keyName<Col>`),
- a column selection (`removeAllColumns()` + `addColumn<Col>()`),
- aggregates on the same data: a grouped count, a sum, an average, and a page.

The programs read the seeded MySQL bench database. Every program takes the DSN from `ORM_BENCH_MYSQL_DSN` and exits with status 1 without connecting when it is unset or empty.

```sh
go run ./examples/complex/go > go.json
php examples/complex/php/main.php > php.json
(cd clients/rust && cargo build -p polyspec-orm-tests) && clients/rust/target/debug/complex > rust.json
diff go.json php.json && diff go.json rust.json                      # identical
```

The members appear in one declared order, and `read_sum` and `like_avg` are binary64 values written as their shortest decimal without a forced fraction (`456000`, not `456000.0`). `make example-check` builds the Rust programs and compares the outputs of this example and of `examples/thin-slice` byte for byte.

Each client plans the statements in its own process. The Rust models are generated by `polyspec-orm-build` when the binary is built.

`docs/examples/complex-query.md` shows additional product-domain shapes. It stays illustrative
because those example tables are not part of the benchmark schema in this repository.

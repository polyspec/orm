# Complex statement demo

One statement with the main parts of the grammar, in three languages, printing the **same JSON**:

- a join child with its own `on()` conditions whose `where` conditions are placed in a group with `or(model)`,
- two levels of relations with options (`groupLimit`, `alias<Name>`, `keyName<Col>`),
- a column selection (`removeAllColumns()` + `addColumn<Col>()`),
- aggregates on the same data: a grouped count, a sum, an average, and a page.

The programs read the seeded MySQL bench database. Every program takes the DSN from `ORM_BENCH_MYSQL_DSN`; the default is `mysql://root@localhost/orm_bench?socket=/tmp/mysql.sock`.

```sh
go run ./examples/complex/go schema/schema.json > go.json
php examples/complex/php/main.php "$PWD/schema/schema.json" > php.json
(cd clients/rust && cargo build --release -p orm-tests) && clients/rust/target/release/complex > rust.json
diff go.json php.json && diff go.json rust.json                      # identical
```

Each client plans the statements in its own process. The Rust models are generated by `orm-build` when the binary is built.

`docs/examples/complex-query.md` shows additional product-domain shapes. It stays illustrative
because those example tables are not part of the benchmark schema in this repository.
